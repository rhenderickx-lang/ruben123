# Electra Proxy — setup in 3 stappen

1. Maak gratis account op vercel.com
2. New Project → "Upload" → sleep deze map erin
3. Settings → Environment Variables → voeg toe:
   Naam: ANTHROPIC_API_KEY
   Waarde: jouw Anthropic API key (https://console.anthropic.com)
4. Redeploy → kopieer de URL
5. Plak de URL in de interview tool onder "Proxy instellen"
